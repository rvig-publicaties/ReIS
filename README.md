# Certificaten Reisdocumenten Informatiesystemen (ReIS)
## Productdomein Identiteitsdragers

Deze repository wordt gebruikt voor het publiceren van (server)certificaten die worden gebruikt om veilig te verbinden met - en gebruik te maken van - de verschillende producten en diensten van Reisdocumenten Informatiesystemen (ReIS).

Nieuwe certificaten worden gepubliceerd in de root van deze repository. Bij publicatie van nieuwe certificaten zal deze README.md ook worden bijgewerkt met een overzicht van de nieuwe certificaten, inclusief de geldigheidsduur. De certificaten waarvan de verloopdatum nadert of reeds is verstreken (en dus dienen te worden vervangen met de nieuwe certificaten), worden verplaatst naar de map 'ARCHIEF'.

Voor vragen of opmerkingen, neem contact op met: info@rvig.nl

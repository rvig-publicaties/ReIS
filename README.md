# IT Productdomein Identiteitsdragers
## Certificaten voor het gebruik van ReIS (Reisdocumenten Informatiesystemen)

Deze repository wordt gebruikt voor het publiceren van (server)certificaten die worden gebruikt om veilig te verbinden met, en gebruik te maken van de verschillende producten en diensten van Reisdocumenten Informatiesystemen (ReIS).

Nieuwe certificaten worden gepubliceerd in de root van deze repository. Bij publicatie van nieuwe certificaten zal deze README.md ook worden bijgewerkt met een overzicht van de nieuwe certificaten, inclusief de geldigheidsduur.

Voor vragen: info@rvig.nl
